## 4. Web-Zahlungen freischalten (Pro + Boosts + 14-Tage-Testabo)

> **Compliance — WICHTIG:** Zahlungen laufen **nur im echten Web-Browser**
> (app.jamie-app.com in Safari/Chrome). In der **Play-TWA** und der **iOS-App**
> sind Kauf-Flächen per Code ausgeblendet (`isTWA`/`isAppShell`) — Stripe für
> digitale Güter in einer Store-verteilten App verstösst gegen Google-Play-/
> Apple-Billing und riskiert Rauswurf. In-App-Kauf (Play Billing / StoreKit) ist
> ein **separates späteres Projekt**. Der Testabo-Umsatz kommt vorerst nur von
> Browser-Nutzern.

**Empfehlung: zuerst mit Stripe-TEST-Keys testen, dann auf Live umstellen.**

**Stripe-Dashboard (Live-Modus):**
- [ ] Live-Keys: `STRIPE_SECRET_KEY` (sk_live_…), `STRIPE_PUBLISHABLE_KEY` (pk_live_…)
- [ ] **Webhook 1 (Boosts):** Endpoint `https://api.jamie-app.com/api/boost/stripe/webhook`,
      Event `payment_intent.succeeded` → Signing-Secret → `STRIPE_WEBHOOK_SECRET`
- [ ] **Webhook 2 (Abos):** Endpoint `https://api.jamie-app.com/api/subscription/stripe/webhook`,
      Events `customer.subscription.created/updated/deleted`, `invoice.payment_succeeded`,
      `invoice.payment_failed` → Signing-Secret → `STRIPE_SUBSCRIPTION_WEBHOOK_SECRET`
- [ ] **Customer Portal aktivieren** (Settings → Billing → Customer portal → Activate)
      — sonst „Abo verwalten"-Button = Fehler.

**Railway env:**
- [ ] `STRIPE_SECRET_KEY`, `STRIPE_PUBLISHABLE_KEY`, `STRIPE_WEBHOOK_SECRET`,
      `STRIPE_SUBSCRIPTION_WEBHOOK_SECRET`
- [ ] `FRONTEND_URL=https://app.jamie-app.com` (Portal-Return-URL)
- [ ] (Das Frontend-Flag `PAYMENTS_ENABLED=true` steckt schon im Build — kein env nötig.)

**Legal (Tina, vor breiter Bewerbung — kein Code-Blocker):**
- [ ] Trial-Wording + **§18-FAGG-Consent** im ProModal gegenchecken: beim Gratis-
      Trial wird heute NICHTS abgebucht → Formulierung „sofortige Leistung /
      Widerrufsverlust" ggf. anpassen. Trial-Offenlegung („14 Tage gratis, danach
      X €, jederzeit kündbar") ist am Kaufpunkt eingebaut.
- Mechanik: Testabo gilt **nur für Erst-Abonnenten** (kein Cancel-&-Resubscribe-
  Farming), Karte wird per SetupIntent hinterlegt, automatische Abbuchung nach 14
  Tagen; ohne hinterlegte Karte kündigt Stripe automatisch.
